## 项目简介

CyberToolkit 是社团成员共同维护的开源安全工具箱，目标是把 CTF 比赛和日常学习中常用的小工具整合成一套易用、易扩展的命令行工具集。

## 规划模块

- 编码 / 解码：Base64、Hex、URL、Unicode 互转
- 古典密码：凯撒、维吉尼亚、栅栏密码的加解密
- Web 辅助：请求重放、常用 Payload 生成
- Misc 利器：文件头识别、隐写初筛

## 参与开发

项目仓库即将在社团 GitHub 组织下开源，欢迎所有社员贡献代码，具体的 Good First Issue 会在群里发布。
