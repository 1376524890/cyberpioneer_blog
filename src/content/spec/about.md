# 关于我们 / About Us

**Cyber先锋社**（Cyber Pioneer Club）是一支专注于**信息技术**的学生技术社团。我们汇聚了一群热爱技术、崇尚探索、乐于创造的同学，致力于打造校园里最有活力的编程学习与技术实践平台。

## 💻 我们做什么

- **编程语言学习**：Python / C++ / Java 等主流语言的入门教学与进阶实践，配套站内[教程板块](/series/)系统学习
- **Web 开发**：从前端三件套到现代框架，从建站部署到全栈项目实战
- **网络安全**：CTF 竞赛训练（Web/Pwn/Reverse/Crypto/Misc）、Web 安全、靶场实战，在合法合规的前提下锤炼攻防技术
- **AI 应用探索**：大模型、AI 编程工具的实践与分享（系列课程筹备中）
- **技术分享会**：每周技术沙龙，社员轮流上台讲讲自己最近在折腾的技术

## 🎯 社团宗旨

> 探索、分享、创造。

我们相信技术的价值在于**理解世界并创造价值**——写出一个程序、搭好一个网站、训练一个 Agent、守住一道防线，都是探索的证明。在这里，你可以系统学习、动手实践、结识志同道合的伙伴。
